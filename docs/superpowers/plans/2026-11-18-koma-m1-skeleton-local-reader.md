# Koma M1 — Skeleton, Local Comics & Reader Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce an installable unsigned `Koma.ipa` (TrollStore, iOS 16.3.1) with a 5-tab shell, a local-comics library (CBZ/ZIP/PDF/image folders), a detail page, and a buttery UIKit reader (paged LTR/RTL/vertical + webtoon) that saves progress.

**Architecture:** All platform-independent logic (models, source protocol, GRDB database, local import, reader session math) lives in a local Swift package `KomaCore`, unit-tested with `swift test` on CI. The app target (SwiftUI shell + UIKit reader) depends on `KomaCore` and is generated by XcodeGen. GitHub Actions on `macos-14` runs the tests and builds the unsigned IPA.

**Tech Stack:** Swift 5.9+, SwiftUI (iOS 16), UIKit, XcodeGen, GRDB 6.x, ZIPFoundation 0.9.x, Nuke 12.x (+NukeUI), PDFKit, XCTest, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-18-comic-reader-design.md` (this plan covers milestone M1 in §7; M2–M4 get their own plans).

## Global Constraints

- Deployment target **iOS 16.0**; no SwiftData, no `@Observable`, no iOS 17-only APIs. State via `ObservableObject` / `@Published`.
- Bundle id `com.koma.reader`, product name `Koma`, iPhone only (`TARGETED_DEVICE_FAMILY = 1`).
- IPA is built with `CODE_SIGNING_ALLOWED=NO`; no special entitlements; standard sandbox.
- Info.plist: `CADisableMinimumFrameDurationOnPhone = YES`; `UIFileSharingEnabled = YES`; `LSSupportsOpeningDocumentsInPlace = YES`.
- UI language: Simplified Chinese strings (hard-coded for M1; no localization tables yet). Code, comments and commit messages in English.
- Prefetch defaults: **2 pages before, 5 pages after** current page.
- Image fade-in: **0.15 s**. Corner radius: covers **10 pt**, cards **16 pt**. Default accent: coral (`#FF6F61`). Reader background: pure black.
- Local library root: `Documents/Library/<mangaId>/<chapterId>/<0001.ext>`.
- No third-party site scrapers anywhere in the repo.
- The developer machine is Windows without Xcode: every "run tests" / "build" step is verified on GitHub Actions (push, then read the workflow result). `swift test` commands below are what CI runs.

## Deferred From M1 (spec items intentionally left to later plans)

- Reader fit modes (fit width/height/screen/original), white-border crop, slider thumbnail preview → M4.
- MangaDex, global search, OPDS, JS plugins, WebView challenge → M2/M3.
- Downloads, backup/restore → M4.

## Review Focus

1. **ZIP/CBZ with Chinese filenames stored in GBK/CP437** (common from Chinese sites) — import must not fail; pages keep correct order. → test in Task 4.
2. **Archives containing junk** (`__MACOSX/`, `.DS_Store`, `Thumbs.db`, `.txt`, nested folders) — only images are imported, ordered by natural sort of their full relative path. → test in Task 4.
3. **Corrupt / empty archive or a folder with zero images** — import throws `LocalImportError.noImages`, nothing is written to the library, the UI shows a toast instead of crashing. → test in Task 4.
4. **App killed mid-chapter** — reopening the manga resumes at the saved chapter + page. → test in Task 3 (progress round-trip) and Task 5 (session restores index).
5. **RTL mode** — tapping the *left* zone goes to the *next* page and the page slider is mirrored. → test in Task 5 (`TapZoneResolver`).

### Task 4: Local import and LocalSource

**Files:**
- Create: `Local/LocalImporter.swift`, `Local/FilenameDecoding.swift`, `Local/LocalSource.swift`
- Test: `LocalImporterTests.swift`, `LocalSourceTests.swift` (fixtures generated at test time with ZIPFoundation into a temp dir)

**Interfaces:**
- Consumes: models, `MangaSource`, `naturallySorted()`.
- Produces:
  - `public enum LocalImportError: Error, Equatable { case noImages, unsupportedType(String), alreadyImported(String) }`
  - `public struct LocalImporter { init(libraryRoot: URL); func importItem(at url: URL) throws -> MangaRef }`
    - `.cbz`/`.zip` file → one manga, one chapter (title = filename without extension).
    - Folder of images → one manga, one chapter.
    - Folder whose children are subfolders and/or archives → one manga (folder name), one chapter per child, ordered by natural sort.
    - Pre-rendered image folder from the app's PDF renderer goes through the folder path (PDF itself is handled in Task 6).
    - Writes `Documents/Library/<mangaId>/<chapterId>/0001.<ext>` …, plus `<mangaId>/manga.json` `{title, chapters:[{id,title}] , importedFrom: <original filename>}`; cover = first page of first chapter.
    - `mangaId` = SHA-256 of original filename + byte size, first 16 hex chars; same id already present → `alreadyImported(title)`.
    - Images accepted: `jpg jpeg png webp gif heic avif` (case-insensitive). Skip anything whose path contains `__MACOSX` or a component starting with `.`.
    - Writes into a temp dir first and moves it into place only on success (no half-imported manga on failure).
  - `func decodeZipEntryName(_ raw: Data, isUTF8Flag: Bool) -> String` — UTF-8 if flagged or valid UTF-8; else try GB18030 (`CFStringEncodings.GB_18030_2000`), else CP437.
  - `public struct LocalSource: MangaSource { id = "local"; name = "本地漫画"; language = "multi"; init(libraryRoot: URL) }` — `popular`/`latest` list all mangas (by import date desc / title), `search` filters titles case-insensitively, `details`/`chapters`/`pages` read `manga.json` and the folder; page URLs are `file://` URLs.
